/* Typora TypeMark shell rules (project-specific overrides only).
 *
 * 方案 A「原生骨架直供」：Typora base.css / base-control.css / window.css / mac.css
 * 原样注入（不经适配器重写），提供 sidebar/outline/file-tree/search 的完整原生布局。
 * 本文件只保留【本项目环境特有】或【主动对抗实物行为】两类规则：
 *   - 仅保留实物没有、或本项目环境（Chrome/milkdown）需要的适配（B 类），
 *     以及主动对抗实物行为的覆盖（C 类，附注释说明原因）。
 * 注入顺序：base → base-control → window → mac → 本文件(shell) → 用户主题，后者覆盖前者。 */

/* ============================================================
 * B 类：项目自造 UI 的 Typora reset 隔离。
 * Typora base.css 的 html/body/h1-h6/p/ul/a 等全局 reset 现在全局生效（无 .typora-theme-scope
 * 作用域），会穿透项目自造的非 Typora UI（设置弹窗、菜单等）。给这些区域加 .inkwing-chrome
 * 后，用 all:revert 把继承态恢复到浏览器默认，使其不受 Typora reset 影响。各组件自行用
 * 自己的 CSS（SettingsModal/styles.css 等）定义视觉。
 * ============================================================ */
.inkwing-chrome,
.inkwing-chrome *,
.inkwing-chrome *::before,
.inkwing-chrome *::after {
  /* 不用 all:initial（会清掉 display 等关键值导致塌陷），用 revert 恢复 UA 默认，
     再由组件 CSS 覆盖。box-sizing 由本项目 global.css 已统一为 border-box。 */
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
}

/* ============================================================
 * B 类：搜索选项按钮。Typora 用 #searchpanel-case/word-option-btn，本项目改名为
 * #filesearch-*-option-btn（去 panel 前缀），故 Typora 的按钮规则匹配不到本项目 DOM，
 * 必须自带。regexp 按钮 Typora base-control 完全没有，本项目新增。
 * ============================================================ */
#filesearch-case-option-btn {
  right: 64px;
}

#filesearch-word-option-btn {
  right: 42px;
}

#filesearch-regexp-option-btn {
  right: 20px;
}

/* ============================================================
 * B 类：去除 Chrome 对 type="search" 的原生装饰（取消按钮/装饰）。
 * Typora 跑在 WKWebView 默认不绘制这些，实物 CSS 无需处理；Chrome 会画，故此处去除。
 * #file-library-search-input 的盒模型/边框/flex 已由实物 mac.css 提供，不在此重复。
 * ============================================================ */
#file-library-search-input::-webkit-search-cancel-button,
#file-library-search-input::-webkit-search-decoration {
  -webkit-appearance: none;
}

/* ============================================================
 * B 类：#close-outline-filter-btn 的显示规则。
 * 基础定位（padding/opacity/position）已由 Typora 实物 window.css 提供；
 * 本项目新增独立的 close-outline-filter-btn，需 .ty-show-outline-filter 态显示它
 * （Typora 的 close 按钮复用 #close-outline-btn，无此独立按钮的显隐规则）。
 * ============================================================ */
#typora-sidebar.ty-show-outline-filter #close-outline-filter-btn {
  display: inline-block;
}

/* ============================================================
 * B 类：命中子串的高亮色。Typora base-control 只设了 opacity:1，没设背景色；
 * 本项目新增黄底高亮，使匹配子串更醒目。
 * ============================================================ */
.ty-file-search-match-text {
  background-color: rgba(248, 192, 116, .3);
}

/* ============================================================
 * C 类：去除 Chrome 默认焦点虚线框。
 * Typora base-control 对 .file-library-node:focus > .file-node-content 画
 * currentColor dashed 1px 虚线（Typora 在 WKWebView 需要它）。本项目跑在 Chrome，
 * 默认焦点环已足够，故主动覆盖为 none。若希望与 Typora 一致画虚线，删除本块即可。
 * ============================================================ */
.file-library-node,
.file-node-content {
  outline: none;
}

.file-library-node:not(.file-node-root):focus > .file-node-content {
  outline: none;
}
